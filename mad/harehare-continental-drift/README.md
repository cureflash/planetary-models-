# ハレ晴レユカイ × 大陸移動説 MAD

ウェゲナーの大陸移動説を、2000年代のニコニコ動画・FLASH系MADに寄せたテンポで編集するための制作ディレクトリです。

## 編集環境

- AviUtl ExEdit2
- 画面比率: 4:3
- 基準解像度: 640×480
- 音源はリポジトリに含めない

AviUtl ExEdit2本体もこのリポジトリには含めません。公式配布版を使用してください。

## ディレクトリ

```text
harehare-continental-drift/
├─ README.md
├─ .gitignore
├─ storyboard/
│  ├─ storyboard.md
│  └─ timeline.csv
├─ assets/
│  ├─ README.md
│  └─ audio/
│     └─ README.md
├─ project/
│  └─ README.md
└─ credits/
   └─ credits.md
```

## 最初にやること

1. `assets/README.md` の一覧に沿って画像素材を用意する。
2. 使用した素材の出典・ライセンスを `credits/credits.md` に記録する。
3. 手元の音源を `assets/audio/` に置く。音源は `.gitignore` でGit管理から除外する。
4. AviUtl ExEdit2で640×480のプロジェクトを作る。
5. `storyboard/storyboard.md` の順番で素材を配置する。
6. 実際の曲に合わせて `storyboard/timeline.csv` の `start` / `end` を埋める。
7. AviUtlのプロジェクトファイルを `project/` に保存する。

## 演出方針

現代的な滑らかなモーショングラフィックスより、静止画・巨大文字・急拡大・瞬間切替を優先します。

- 白黒のウェゲナー写真を雑に切り抜いて大写し
- 世界地図をそのまま背景に置く
- 南米とアフリカを画面上で強引に接合
- 重要語を全画面ゴシック体で表示
- ビートに合わせて急拡大、回転、横飛ばし
- 一瞬だけネガ反転・色相変化・画面揺れ
- 同じ人物写真の複製を並べる
- 前半は「荒唐無稽に見える仮説」、後半は「後世の証拠による答え合わせ」にする
