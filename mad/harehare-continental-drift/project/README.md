# AviUtl プロジェクト

AviUtl ExEdit2で作成したプロジェクトファイルをこのフォルダに保存します。

プロジェクトファイル形式はAviUtl側で実際に保存して生成してください。このリポジトリでは、未確認の形式を推測してダミーのプロジェクトファイルは作りません。

## 初期設定

- 画面: 4:3
- 基準解像度: 640×480
- 背景: 黒を基本
- 素材: `../assets/`
- 音源: `../assets/audio/`

## レイヤーの目安

```text
上: 文字・フラッシュ・ノイズ
   ウェゲナー写真
   大陸・証拠図版
   背景地図
下: 音源
```

素材の移動やファイル名変更をすると参照が切れる可能性があるため、AviUtlで読み込んだ後は `assets/` の相対的な配置を維持してください。
