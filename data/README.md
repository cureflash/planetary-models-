# Mars reference data

`mars_reference_2020_2030.csv` contains one row per day from 2020-01-01 through 2030-01-01.

It is generated by `tools/generate_reference.py` from JPL Solar System Dynamics' "Approximate Positions of the Planets" formulae and the 1800–2050 element table:

https://ssd.jpl.nasa.gov/planets/approx_pos.html

The table stores the daily Earth-centered J2000 ecliptic XY direction to Mars, geocentric ecliptic longitude, and distance. The generation script obtains that relative vector from JPL's Earth-Moon-barycenter and Mars heliocentric approximations.

JPL describes these as lower-accuracy formulae and recommends Horizons for high-precision ephemerides. The bundled file is therefore a reproducible educational reference track rather than raw telescope observations or a full Horizons ephemeris.
